# Insurance & Training Management Application

A full-stack Flask web application integrated with Supabase (PostgreSQL), featuring automated database migrations via Flask-Migrate and robust unit testing using Pytest.

## Features
- **User Authentication & Management**: Role-based access control and user tracking.
- **Request Workflows**: Manage and track insurance and training requests across governorates.
- **Automated Database Migrations**: Seamless schema versioning using `Flask-Migrate` and Alembic.
- **Testing Suite**: Built-in automated tests using `pytest`.

## Tech Stack
- **Backend**: Python, Flask, Flask-SQLAlchemy, Flask-Migrate
- **Database**: Supabase (PostgreSQL)
- **Testing**: Pytest
